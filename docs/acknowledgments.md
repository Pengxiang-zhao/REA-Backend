# Acknowledgments

[REA](https://github.com/morluto/rea) supplies reverse-engineering capabilities used by the APK analysis adapter. It is installed separately. REA-Backend is an independent project and is not an official REA release.

The Node bridge uses the separately installed Model Context Protocol client library. Android SDK tools and Apktool support package inspection and client validation. Upstream tools remain subject to their respective licenses.

This repository contains the pipeline implementation, project-authored documentation and diagrams, and synthetic test fixtures. It does not distribute upstream tool code, app source trees, APKs, or generated services. Any third-party material included in future releases must retain its applicable license and notices. A license for this project's own code will be selected before a public code release.
